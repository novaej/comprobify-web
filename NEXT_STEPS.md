Docker itself flags both with `SecretsUsedInArgOrEnv` warnings during `deploy-staging.yml`'s build — the actual exposure is limited (only the ephemeral `builder` stage on a GitHub Actions runner sees them; the pushed `runner` stage image doesn't inherit that layer history), but a secret mount would close the gap properly rather than relying on that multi-stage boundary.
